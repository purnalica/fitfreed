# FitFreed

![FitFreed — Your fitness data, freed](assets/brand/fitfreed-logo.svg)

*An open-source fitness data explorer.*

FitFreed is a local-first desktop application for turning personal fitness-platform exports into an understandable, durable history that can be explored beyond the source platform.

> **Project status:** Milestones 1 and 2 capability implementation are complete, and Milestone 3 public-release engineering is active. The versioned Tauri application has documented Polar Flow daily-activity, training-summary, split sleep-result, and dated nightly-recovery compatibility boundaries; complete package-family reporting; source-subject-safe reimport; provider-neutral gap-aware exploration for all four histories; an integrated longitudinal dashboard; and release-shaped installation, update, and automatic recovery evidence. One private reference export has passed the privacy-safe four-domain acceptance predicate. Apple Silicon on macOS 15.0 or later is the supported MVP platform boundary. Production updater and Apple authority, protected GitHub configuration, an exact signed candidate, participant evaluation, and public publication remain open, so no supported release is available and real personal exports remain outside the current boundary.

FitFreed is experimental software provided without warranty. Use it at your own risk and read the [project disclaimer](DISCLAIMER.md) before running any build.

## Why FitFreed exists

Downloading personal data is necessary but not sufficient. A ZIP archive full of machine-readable files provides little practical freedom without trustworthy software that can interpret, reconcile, visualize, preserve, and export the information.

FitFreed's central argument is:

> **GDPR-enabled portability + open-source software = meaningful user freedom.**

The EU Data Act provides complementary context for data generated by connected devices. FitFreed is not a legal service, compliance product, medical device, or diagnostic tool.

## Product direction

The implemented MVP capability set:

- Imports a Polar Flow personal-data ZIP directly.
- Reports supported, ignored, and unrecognized content explicitly.
- Reconciles repeated and overlapping exports without duplicates or data loss.
- Stores provider-neutral information locally.
- Explores activity, training, sleep, and recovery history visually.
- Supports `en-US` and `es-ES` from the first release.
- Provides a verifiable update-notification and installation path.

Polar Flow is the first importer, not the product identity. Later importers may support Garmin and other providers through the same source boundary.

## Product principles

- Local-first and offline-capable core use.
- Clean Architecture and Domain-Driven Design.
- Provider-neutral domain and application layers.
- Small, runnable vertical increments.
- Unit, integration, and end-to-end tests as primary quality evidence.
- Exceptional user and contributor experience.
- Open formats, portable backups, recoverable migrations, and no replacement lock-in.
- No real personal exports or derived personal data in the repository.

## Contributing

FitFreed is being designed for external contribution from the start. Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a change. Never attach a real provider export, application library, route, screenshot, log, or diagnostic bundle containing personal data to an issue or pull request.
