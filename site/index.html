01 · WHY

Downloading your data is a right. Using it should be a reality.

A machine-readable archive satisfies access better than it satisfies understanding. FitFreed exists to make a portable history genuinely useful: transparent transformations, durable local storage, open formats and an application no provider can switch off.

GDPR-enabled portability + open-source software = meaningful user freedom
