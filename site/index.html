What the application is for

Find a session. Understand what was recorded. Keep the result.

The source already implements the underlying capabilities. The active migration is making their order, density, and visual explanation match these tasks.

Implemented in source
01

Find the part of the history that matters.

Browse the complete history by sport, date, available evidence, authored label, or imprecise text. Return from detail to the same filters and position.

Implemented evidence · presentation in progress
02

Investigate a session without losing the evidence.

Inspect recorded structure, route points, signals, zones, gaps, exact values, and provenance. The accepted map-led workbench is the active presentation migration.

Implemented in source · Alpha UX
03

Save and export a result, not just a screenshot.

Create a reproducible report from supported evidence, review sensitive content, and export one self-contained HTML document.

Reports and data exit

A saved report opens as a result.

Editing is deliberate and secondary. The report keeps its subject, evidence choices, order, authorship, source revision, and privacy choices so it can be reviewed again later.

  • Creation starts from a supported session or comparison.
  • A later import never refreshes reviewed evidence silently.
  • Export produces deterministic HTML with no external request.

Alpha interaction The purpose and integrity boundary are accepted; hierarchy and composition remain open to refinement.

Data control

Local by default. Inspectable by design. Exportable on purpose.

FitFreed is intended to make an export useful without becoming another data silo.

01

Local processing

Core use needs no FitFreed account or mandatory hosted service. Precise routes stay on the current device.

02

Visible provenance

Recorded facts, mappings, calculations, authored material, gaps, and unsupported content remain distinguishable.

03

Supported exit

Self-contained report export exists today. Versioned backup and normalized-data export remain explicit MVP requirements.

04

Open implementation

GPL-3.0-or-later source, documented formats, and public architecture decisions make the product inspectable and repairable.

Project status

Current source, active migration, and later scope.

The sections below separate code that exists from accepted work in progress and later ideas. There is no supported public download yet.

Implemented in source

Current capability
  • Polar Flow ZIP validation and import
  • Explicit supported, ignored, and unrecognized coverage
  • Safe exact and cumulative reimport
  • Provider-neutral SQLite history for activity, training summaries, structure, routes, signals, sleep, and recovery
  • Bounded visual comparison and longitudinal context
  • User-authored sport classification and complete-history session search
  • Chronology, source-separated calendar discovery, session comparison, and restart restoration
  • Recorded exercise, mixed-sport, source-lap, automatic-lap, and pause inspection
  • Private local primary and transition route traces with paginated exact points
  • Gap-aware supported signal charts with paginated exact samples
  • Exact recorded heart-rate, speed, and power zones with applicable aggregates
  • Reusable personal segment criteria with exact locally derived session views
  • Library Home, post-import summary, and resumable exploration
  • Persistent navigation, offline export guidance, and allowlisted official links
  • Durable language, appearance, and content zoom settings
  • en-US and es-ES, packaging, update recovery, and release-shaped tests
  • On-demand privacy-bounded session provenance and reconciliation history
  • Selectable same-role signal alignment with exact sample paths
  • Composable session and route reports with privacy-reviewed self-contained HTML export
  • Versioned training-period findings, comparisons, charts, exact tables, and coverage views
  • Question-led, exploration-led, session-led, and blank report starts with durable authored results
  • Deliberate stale-report refresh through an exact current-evidence review
  • Origin-aware navigation between saved reports and their exact session or comparison source
