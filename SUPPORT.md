# Support

## Current availability

FitFreed has a complete executable MVP and public-release engineering path but no supported release. Current support covers contributor setup and the independently generated synthetic journey documented in the [development preview guide](docs/user/development-preview.md). The [public macOS 0.1.0 guide](docs/user/public-macos-0.1.0.md) is inactive until the [macOS readiness ledger](docs/testing/public-release-readiness.md) closes its production-trust, protected-distribution, exact-candidate, and participant-evaluation gates. The [public Linux 0.1.0 guide](docs/user/public-linux-0.1.0.md) is also inactive until the [Milestone 4 ledger](docs/plans/milestone-4.md) closes the Linux package, exact-candidate, clean Ubuntu, and macOS-publication dependency gates. Real personal exports, end-user installation, and update support begin only with a version that explicitly activates and verifies those boundaries.

## Where requests belong

- Reproducible defects and bounded feature proposals belong in GitHub Issues using the relevant repository template.
- Security vulnerabilities follow [SECURITY.md](SECURITY.md) and must not be reported publicly.
- Conduct incidents follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- General provider-account, export-request, legal, medical, training, or device-support questions are outside project support.

Before opening a report, remove all personal data and reproduce the condition with synthetic input where possible. Never attach a real provider export, local library, route, screenshot, log, or diagnostic bundle containing private values.

## Support boundaries

Support covers documented FitFreed behavior on declared platform and application versions. It does not cover provider services, unsupported export variants, modified builds, third-party packaging, operating systems outside the support matrix, or interpretation of health information as medical advice.

Compatibility gaps are still valuable reports when they describe the structural condition without exposing personal content.
