# Library Home Read Model Version 9

Version 9 retains every range, domain coverage, question, highlight, post-import, resumable exploration, bounding,
ordering, privacy, and exact relationship projection rule from [version 8](library-home-v8.md). It adopts reusable
personal correlations and provider-normalized defaults from [training sports version 6](training-sports-v6.md).

`query_library_home` returns
[`library-home-v9.schema.json`](../../../schemas/library-home-v9.schema.json) with `version` 9.

## Reusable sport projection

`sportCollectionCount` remains the complete number of exact represented base collections. A reusable personal
relationship may acquire compatible exact members after a non-identical cumulative import without changing its user
revision. Home includes those members in the chosen identity, `sessionFilterRefs`,
`representedCollectionCount`, and `sessionCount`; it never presents the reviewed relationship as fixed historical
coverage.

Provider-normalized visible sports follow the same exact-member projection. Equal documented provider evidence may
therefore contribute one recognized Home summary even when source records contain distinct opaque identifiers.
Every exact member capability remains in `sessionFilterRefs`, source origins remain separate, and an explicit personal
relationship takes precedence. No private selector, provider identifier, source code, or synthetic visible capability
enters transport.

Changing sport-correlation reuse, normalization eligibility, precedence, aggregation, retained Home behavior, or
privacy requires a new response version.
