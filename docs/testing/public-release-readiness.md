# Public macOS Release Readiness

## Decision status

FitFreed 0.1.0 is **not accepted or publicly available**. The E1 through E5 experience is implemented in source and E6 hardening is in progress. The ADR 0020 Pages compositor and localized product site are implemented and live without an application download. Production updater trust, Apple authority, protected GitHub release controls, an exact sealed candidate, human evaluation, and explicit application-publication authority do not yet exist.

This is the single current readiness ledger for the first public macOS release. The former [private-alpha ledger](private-alpha-readiness.md) remains the detailed source for its completed and deferred Milestone 2 evidence; it no longer owns the current release decision.

The states mean:

- **Passed**: complete durable evidence exists for the named version-independent or unchanged capability boundary.
- **Passed locally**: deterministic local evidence exists, but the exact source still requires its hosted result.
- **In progress**: the accepted implementation boundary is actively being completed and has not reached its evidence gate.
- **Pending hosted verification**: a required GitHub result for the exact release-affecting source is absent or running.
- **Open external gate**: accountable configuration, credential, or third-party trust evidence does not exist.
- **Awaiting exact candidate**: the procedure exists but can run only against production-authority bytes.
- **Not authorized**: the irreversible external action has not been approved.

No row changes state by implication. A green source build does not prove Apple trust, environment protection, human usability, public bytes, or publication authority.

## Final acceptance rule

FitFreed 0.1.0 may be called a public release only when every applicable row is **Passed** for one exact immutable source and candidate, both GitHub approval records correspond to that workflow run, and no required evidence belongs only to a development, synthetic, ad-hoc, private-alpha, earlier-source, or rebuilt artifact.

The release decision must record the exact tag, source revision, immutable workflow run, Release URL, Pages deployment, manifest digest, sealed-candidate manual result, and final remote verification. It must not record secret values, personal data, participant identity, machine-local paths, exact workstation details, or raw diagnostics.
