## Highlights

- Import supported Polar Flow takeout families into a provider-neutral local library.
- Explore daily activity, training summaries, primary sleep, and dated nightly recovery independently or through one aligned longitudinal view.
- Reimport exact or later exports without duplicating canonical history, while retaining explicit conflicts and complete artifact-family coverage.
- Use localized English (United States) and Spanish (Spain) interfaces with exact accessible alternatives for every visualization.

## Compatibility

This private development candidate targets Apple Silicon macOS. The minimum supported macOS version remains a release gate. Performance acceptance uses the passing hosted macOS and clean local Apple Silicon campaigns and does not claim identical timing across every supported Mac. The included compatibility matrix declares direct library migration from SQLite schemas 1 through 9 and no prior application-version upgrade baseline because FitFreed has not released an earlier application.

Input compatibility is limited to the documented Polar Flow daily-activity, training-summary, split sleep-result and sleep-score, and dated nightly-recovery shapes. Recognition of another artifact family does not mean that its records are imported.

## Privacy and data

Fitness history, source provenance, locale preference, and update policy state remain in the local FitFreed library by default. The ordinary build has no account, analytics, synchronization service, configured update endpoint, or production trust key. It does not transmit imported facts, provider data, locale, library schema, installation identity, or usage data.

## Known limitations

- This is unsigned, non-notarized private development material, not an available or supported alpha release.
- Garmin and other providers are not implemented.
- Routes, full-resolution training and physiological samples, and undated recovery samples are not imported.
- There is no supported user-controlled backup, restore, portable normalized export, or in-application library deletion workflow.
- Production update discovery and installation remain unavailable until a private HTTPS endpoint and protected signing authority are configured.
- Minimum-platform, manual accessibility, realistic-usability, controlled-distribution, and participant-acceptance gates remain open.

## Installation and recovery

Verify the complete version directory and `SHA256SUMS` before mounting the DMG. Install only through the candidate-matched private macOS procedure; never disable Gatekeeper globally or alter system-wide security settings. Preserve each original provider ZIP independently.

Moving `FitFreed.app` to the Trash leaves the separate local library intact. Automatic application-and-library preservation immediately before an authorized update is update-recovery state, not a general backup facility.
