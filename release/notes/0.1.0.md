## Compatibility

FitFreed 0.1.0 supports Apple Silicon on macOS 15.0 or later. Package metadata, executable deployment target, release contracts, and the hosted Apple Silicon campaign share that boundary. Performance acceptance uses the passing hosted macOS and clean local Apple Silicon campaigns and does not claim identical timing across every supported Mac. The included compatibility matrix declares direct library migration from SQLite schemas 1 through 35 and no prior application-version upgrade baseline because FitFreed has not released an earlier application.

Input compatibility is limited to the documented Polar Flow daily-activity, training summary, exercise/lap/pause structure, route, supported interval-signal series, supported recorded training-zone groups, scheduled and favourite training targets, split sleep-result and sleep-score, and dated nightly-recovery shapes. Recognition of another artifact family does not mean that its records are imported.

Structured training intent can be explored independently from recorded sessions, included in a saved report, and
exported either as exact normalized JSON or deterministic self-contained HTML. A planned report is bound to one exact
planned-library revision and never presents an objective, phase, transition, or repetition as recorded completion.

## Privacy and data

Fitness history, source provenance, locale preference, and update policy state remain in the local FitFreed library by default. FitFreed has no account, analytics, or synchronization service. Update checks do not transmit imported facts, provider data, locale, library schema, installation identity, or usage data.

## Known limitations

- Garmin and other providers are not implemented.
- External route maps, unsupported provider-defined zone kinds, unsupported training-signal types, and undated recovery samples are not included.
- There is no supported user-controlled backup, restore, portable normalized export, or in-application library deletion workflow.
- Compatibility is limited to the documented provider-export shapes; recognition of another family does not mean its records are imported.

## Installation and recovery

Verify the complete version-matched evidence before mounting the DMG. Follow only the installation procedure supplied by the same distribution channel; never disable Gatekeeper globally or alter system-wide security settings. Preserve each original provider ZIP independently.

Moving `FitFreed.app` to the Trash leaves the separate local library intact. Automatic application-and-library preservation immediately before an authorized update is update-recovery state, not a general backup facility.
