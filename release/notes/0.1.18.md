## Highlights

- Add the accepted MVP capability set to an x86-64 Windows per-user installer while retaining the Apple Silicon
  macOS and x86-64 Ubuntu Desktop distributions.
- Import supported Polar Flow takeout families into a provider-neutral local library and safely reassess exact or
  cumulative reimports.
- Explore activity, sleep, recovery, training sessions, sport identities, routes, signals, zones, comparisons, and
  durable reports with privacy-reviewed self-contained HTML export.
- Use localized English (United States) and Spanish (Spain) interfaces with exact accessible alternatives for every
  visualization.

## Compatibility

FitFreed 0.1.18 supports Apple Silicon on macOS 15.0 or later and x86-64 Ubuntu Desktop 24.04 and 26.04 LTS. It also
provides an experimental x86-64 Windows 11 per-user package whose automated admission runs on hosted Windows rather
than an exact Windows 11 client. Package metadata and release contracts preserve that distinction. The included
compatibility matrix declares direct library migration from SQLite schemas 1 through 37 and exact application update
and recovery from the macOS and Linux 0.1.12 baseline. There is no earlier Windows application baseline.

Input compatibility is limited to the documented Polar Flow daily-activity, training summary, exercise/lap/pause
structure, route, supported interval-signal series, supported recorded training-zone groups, scheduled and favourite
training targets, split sleep-result and sleep-score, and dated nightly-recovery shapes. Recognition of another
artifact family does not mean that its records are imported.

## Privacy and data

Fitness history, source provenance, locale preference, and update policy state remain in the local FitFreed library by
default. FitFreed has no account, analytics, or synchronization service. Update checks do not transmit imported facts,
provider data, locale, library schema, installation identity, or usage data.

## Known limitations

- Garmin and other providers are not implemented.
- External route maps, unsupported provider-defined zone kinds, unsupported training-signal types, and undated
  recovery samples are not included.
- There is no supported user-controlled backup, restore, portable normalized export, or in-application library
  deletion workflow.
- Compatibility is limited to the documented provider-export shapes; recognition of another family does not mean its
  records are imported.

## Installation and recovery

Verify the complete version-matched evidence before installing a package. Follow only the installation procedure
supplied by the same distribution channel; never disable native operating-system security controls or alter
system-wide security settings. Preserve each original provider ZIP independently.

Removing the application leaves the separate local library intact. Automatic application-and-library preservation
immediately before an authorized update is update-recovery state, not a general backup facility.

## Support

FitFreed is experimental GPL-3.0-or-later software provided without warranty and at the user's own risk. Reports must
follow the repository support and security boundaries and must never include a personal export, FitFreed library,
route, fitness value, identifier, private endpoint, signing material, or screenshot containing personal history.
